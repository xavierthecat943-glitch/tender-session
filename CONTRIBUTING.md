# Contributing to tender-session

Thank you for your interest in contributing!

## Getting Started

1. Clone the repository
2. Enter the development shell: `nix flake show` then `nix develop`
3. Make your changes
4. Test thoroughly before submitting

## Development Guidelines

- Keep the session minimal and focused
- Prioritize clarity over features
- Document any new functionality
- Follow existing code style

## Submitting Changes

1. Create a feature branch
2. Commit with clear messages
3. Open a pull request with a description of changes

## Code of Conduct

Be respectful and constructive in all interactions.
