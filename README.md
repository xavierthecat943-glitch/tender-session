# tender-session

A clear and calm NixOS session installer focused on simplicity and functionality.

## Overview

tender-session is a minimal NixOS session that removes the complexity of traditional desktop environments. It provides a straightforward kitty terminal-based session without unnecessary graphics overhead.

## Goals

- **Simplicity**: Easy to understand and install
- **Clarity**: Clear configuration and setup process
- **Functionality**: Focus on getting the session working reliably
- **Minimal**: Kitty terminal only, no bloated UI
